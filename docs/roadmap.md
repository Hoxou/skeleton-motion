# Roadmap

The roadmap preserves a useful local product at every stage. Dates are intentionally not promised yet.

## Now — generator and proof set

- coordinated two-to-four-asset generation;
- source-aware light/dark styling;
- transparent animated SVGs plus optional media exports;
- source-styled Display Room, combined scenes, manifest, and ZIP;
- qa-segnatura reference set and public documentation.

## Next — local Studio

- centered URL/repository input and addressable local job URLs;
- loopback companion for repository access and generation;
- external Codex and Claude Code CLI adapters;
- Ollama/LM Studio adapter for fully local planning;
- structured scene-plan schema, validation, timeouts, and cost telemetry;
- browser job index with generated artifacts stored locally;
- editable art direction and regeneration of one asset without replacing the set.

## Later — optional hosted workspace

- temporary hosted generations with expiring asset storage;
- Google or Discord sign-in;
- personal gallery and reusable brand profiles;
- generation privacy set to private or public;
- a community gallery of recently shared public generations;
- share links and collaborative review;
- hosted planning fallback with a strict low-cost model and monthly spend ceiling.

## Exploration

- motion-story plugins and community presets;
- visual timeline editing;
- Figma export/import;
- Lottie and additional vector targets;
- accessibility linting for motion, contrast, and reduced-motion behavior.

Account and community work begins only after the local workflow is dependable. The public site will never claim it can access a private local repository without the companion.
