# Source analysis

Local repositories are read as data. Skeleton Motion does not import modules, execute package scripts, or start the target application. Generated, dependency, secret, and binary directories are ignored.

For repositories, the analyzer ranks routes, components, style tokens, copy, icons, and interaction evidence. For URLs, it inspects the rendered public page and its resolved CSS. Both routes produce the same normalized analysis model:

- product name and feature evidence;
- ranked scene concepts;
- light and dark palettes;
- semantic color roles, including category colors;
- typography, spacing density, radius, and border treatment;
- optional source-specific backdrop treatment.

Color is assigned by meaning. A speaking waveform remains one signal color; confirmation uses the interaction accent; extra palette colors represent genuinely different entities or categories. Detecting many colors does not license random rainbow styling.

The analyzer output is retained in the manifest so every creative decision can be inspected.
