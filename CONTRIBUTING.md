# Contributing

Install Node.js 20 or newer, then run:

```bash
npm install
npm run verify
```

Keep generated assets transparent by default, preserve source-evidenced styling, and add tests for changes to analysis, planning, preview, or rendering. New motion stories should define one clear product action and should not copy every camera or easing choice from existing stories.

Please open an issue before adding a new export dependency or hosted service. The local generator must remain useful without an account or paid API.
