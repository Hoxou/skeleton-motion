# Support Skeleton Motion

Skeleton Motion is intended to stay useful without an account, hosted subscription, or mandatory API bill.

The PayPal support link will be added here before donations are enabled. Supporting the project will be optional and will not purchase a subscription or unlock private features.

Until then, the most useful support is testing the CLI, reporting a reproducible issue, or contributing a new motion story.

[Open the GitHub project](https://github.com/Hoxou/skeleton-motion)
